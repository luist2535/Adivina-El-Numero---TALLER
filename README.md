# Juego de Adivinar el Número

Esta es una aplicación sencilla en Python de un juego en la consola donde el usuario debe adivinar un número secreto aleatorio entre 1 y 100.

## Funcionamiento de la aplicación

1. Al iniciar el juego, la aplicación genera internamente un número aleatorio entre 1 y 100.
2. El usuario debe ingresar un número por la consola (terminal).
3. La aplicación indicará si el número ingresado es "Demasiado bajo" o "Demasiado alto" en relación con el número secreto.
4. El juego continúa pidiendo números hasta que el usuario adivina el número correcto.
5. Al final, se muestra un mensaje de felicitaciones indicando la cantidad total de intentos realizados.

## Requisitos

- [Python 3.x](https://www.python.org/downloads/) instalado en el sistema.

## Cómo ejecutar

1. Abre una terminal (o consola de comandos) y navega hasta la carpeta donde se encuentra este repositorio.
2. Ejecuta el siguiente comando:

   ```bash
   python app.py
   ```
